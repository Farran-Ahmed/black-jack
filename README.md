# Blackjack Game in C++

A console-based implementation of the classic casino card game **Blackjack** built in C++. This project simulates standard card drawing, hand scoring, and core player choices (hit or stand) in an interactive terminal experience.

---

## Features

* **Interactive Gameplay:** Make decisions in real-time as you play against the dealer.
* **Classic Rules:** Calculates hand totals accurately, accounting for face cards and ace values, while tracking wins, losses, and bust conditions.
* **Clean Console Interface:** Structured text layout optimized for smooth terminal play.

---

## How to Compile and Run

1. **Download or Clone** the repository to your local machine:
   * *Option A (ZIP):* Click the green **Code** button on GitHub, select **Download ZIP**, and extract it.
   * *Option B (Git):* Run `git clone https://github.com/Farran-Ahmed/black-jack.git` in your terminal.
2. **Open a terminal** inside the project folder.
3. **Compile the code** using a C++ compiler (such as `g++`):
   ```bash
   g++ -o blackjack main.cpp
